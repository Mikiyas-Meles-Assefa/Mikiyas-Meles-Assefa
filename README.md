### Research

* [**LLM-Corrector-for-Aphasic-ASR**](https://github.com/cmu-impactlab/LLM-Corrector-for-Aphasic-ASR): Multi-ASR fusion, prompt setups, and Qwen LoRA fine-tuning for post-ASR error correction on disordered speech. Equal-contribution co-author (IEEE ICASSP 2026).
